# firestarter

> Goland VCS project initiator which goal is to speedrun main programing boilerplate on project start 

How to:

1. copy `git@github.com:not-for-prod/firestarter.git`
2. File -> New -> Project From Version Control...
3. Init project - it will rename `firestarter` over project to your folder name

    ```shell
    make init
    ```
   
4. to install `File and Code Templates` and `Live Templates` [read](./tools/goland/README.md)
